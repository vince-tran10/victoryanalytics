## How to re-run (from the repo root)
```bash
cd workspace
export MOVE_RULES=ch7            # Chapter 1-7 TMs + 7-badge tutors
# optional: export EXTRA_TMS=TM134   # only once a Chapter 8 TM is allowed
for f in native Singles Doubles; do FORCE_FORMAT=$f python3 -I ../scripts/team/run.py "$PWD" team/roster.json team/r_$f.json; done
export MOVES='{"Golisopod (Aevian Form)":["Bone Rush","Pin Missile","Swords Dance","Protect"],"Annihilape":["Close Combat","Shadow Punch","Fire Punch","Protect"],"Gholdengo":["Make It Rain","Shadow Ball","Recover","Protect"],"Rhyperior":["Stone Edge","Headlong Rush","Slack Off","Protect"],"Glaceon":["Freeze-Dry","Blizzard","Icy Wind","Protect"],"Leavanny (Aevian Form)":["Rage Powder","X-Scissor","Dragon Claw","Protect"]}'
for f in native Singles Doubles; do TEAM="Golisopod (Aevian Form)|Annihilape|Rhyperior|Gholdengo|Glaceon|Leavanny (Aevian Form)" FORCE_FORMAT=$f python3 -I ../scripts/team/finalize.py "$PWD" team/r_$f.json.pkl team/f9_$f.json; done
```
New export: replace the .txt, then `python3 -I ../scripts/team/roster.py "$PWD" <export.txt> team/roster.json`
(roster.py needs `scripts/` on the path, so run it from `workspace/`). Walkthrough/wiki/forum hosts allowed in this repo's
cloud environment: rejuvenation.wiki.gg, bigjra.github.io, www.rebornevo.com, pokeapi.co.
